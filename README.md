RAG-Paper-Assistant: 基于大模型的本地文献智能问答系统

简介：本项目是一个基于检索增强生成(RAG)技术的本地化智能助手。它专注于学术科研场景，能够读取本地papers文件夹中的PDF论文文献，结合大语言模型API，实现对论文内容的深度理解、智能问答及辅助设计功能。

核心功能：
本地知识库构建：自动扫描并解析根目录下 papers/ 文件夹中的 PDF 文献，利用 Embedding 模型将非结构化文本转化为高维向量。
语义检索与问答：基于 ChromaDB 向量数据库，实现对海量文献的毫秒级语义检索。用户可以用自然语言提问（如“这篇论文的创新点是什么？”），系统将精准定位相关段落并生成回答。
论文设计辅助：针对科研痛点，提供针对性的辅助功能，包括研究方法分析、实验设计建议、文献综述总结等。
隐私安全：核心数据处理在本地完成，仅通过 API 调用大模型推理，确保私有文献数据的安全性。

技术栈
编程语言: Python 3.x
核心框架: LangChain 
向量数据库: ChromaDB (本地持久化存储)
大模型接口: OpenAI API / Claude API / deepseek API 
文档处理: PyMuPDF / pdfplumber

项目结构
dlenv_project/
├── papers/             # [重要] 存放待分析的 PDF 论文文献
├── chroma_db/          # [自动生成] 向量数据库索引文件，无需手动修改
├── local_models/       # [需手动准备] 存放本地运行的 Embedding 模型权重文件
├── .env                # 环境变量配置（API Key 等敏感信息）
├── RAG_base.py         # 核心业务逻辑：文档加载、切片、向量化及问答链构建
├── test_llm.py         # 测试脚本（测试api初始化，测试脚本）
└── .gitignore          # Git 忽略配置
